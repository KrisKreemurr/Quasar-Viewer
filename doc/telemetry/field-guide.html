Usage statistics field guide

Generated from schema_v1.json. Only these typed fields are accepted. Unknown fields are rejected at every nesting level. See implementation.md for units, unsupported measurements and backport details; privacy.md is the publication draft.

The preview displays a literal serialized snapshot. A queued preview is the exact body handed to the sender; an unfrozen live snapshot can change as the window grows. Last sent retains the exact successfully posted bytes in memory only. An off-state preview is a user-initiated one-shot and is neither saved nor sent.

Count gauges use log2 bucket indices: 0 means zero, 1 means 1, 2 means 2–3, 3 means 4–7, continuing through 32. Histograms have 66 bins: below 1 ms, 64 logarithmic bins through 2000 ms, and overflow. Percentiles use approximate bin midpoints. Durations are coarse buckets, not client timestamps. Similar hardware profiles may correlate reports; there is no account or installation identifier.
